# YouTubeVG

Десктопное приложение для генерации YouTube-видео из текстового сценария.
Целевая платформа: macOS Apple Silicon (arm64). Python 3.10+; для разработки
рекомендуется Python 3.11.

## Этап 1 — инициализация

Создан только каркас проекта. UI, загрузка `.env`, API-вызовы, озвучка,
субтитры и монтаж пока не реализованы. На этом этапе ключ API не требуется.
PyQt6, OpenAI SDK, Pillow и Requests будут подключены на соответствующих этапах.
FFmpeg — отдельная системная программа, а не Python-зависимость.

```text
youtubevg/
├── .env.example           # Публичный шаблон настроек
├── .env                   # Локальные настройки, исключены из Git
├── .gitignore
├── pyproject.toml         # Метаданные и конфигурация Python-пакета
├── src/youtubevg/
│   ├── __init__.py
│   ├── __main__.py        # Проверка запуска каркаса
│   ├── ui/               # Будущий интерфейс PyQt6
│   ├── services/         # Будущие интеграции API и оркестрация
│   └── media/            # Будущая работа с изображениями и FFmpeg
├── assets/images/        # Локальные изображения
├── output/               # Результаты, исключены из Git
├── temp/                 # Временные файлы, исключены из Git
└── tests/                # Будущие тесты
```

## Подготовка на Mac

Открой Terminal в каталоге этого репозитория. Используй существующий checkout;
создавать дополнительный Git worktree не требуется.

Проверь архитектуру и Python:

```bash
uname -m
python3.11 --version
```

Ожидается `arm64` и Python 3.11.x. Если Python отсутствует и Homebrew уже
установлен, выполни `brew install python@3.11`. Для нативной arm64-среды запускай
Terminal без Rosetta.

Создай и активируй виртуальное окружение:

```bash
python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install -e .
```

Создай локальные настройки, только если `.env` ещё отсутствует:

```bash
if [ ! -f .env ]; then cp .env.example .env; fi
```

В последующих этапах укажи `OPENAI_API_KEY` в локальном `.env`.
Не отправляй ключ в чат и не добавляй `.env` в Git. Пока приложение не читает
этот файл; загрузку настроек реализуем отдельно.

## Проверка этапа 1

После установки пакета:

```bash
python -m youtubevg
 git check-ignore .env
 git status --short
```

Первая команда сообщает версию и что UI ещё не реализован. Вторая должна
вывести `.env`. Сам `.env`, виртуальное окружение и сгенерированные медиа
не должны появляться среди новых файлов Git.

Без установки пакета можно проверить каркас из корня репозитория:

```bash
PYTHONPATH=src python3 -m youtubevg
```

Сборка `.app` и проверка macOS-интерфейса выполняются на Mac на следующих этапах.
